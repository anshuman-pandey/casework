# Third-party assets

## Inter

The interface bundles the unmodified Inter variable font by Rasmus Andersson and the Inter project authors.

- Project: https://rsms.me/inter/
- Font source: https://rsms.me/inter/font-files/InterVariable.woff2
- License: SIL Open Font License 1.1; the complete notice is in [OFL.txt](casework/web/fonts/OFL.txt).
- Downloaded: 14 November 2026.

The font is served locally. Using Casework does not make requests to a font CDN. Inter retains its own license; the repository's Apache-2.0 license applies to the original Casework code.

The interface icons are original inline SVG paths included with the Casework code.
